How to use this site

Think of this like a small handbook. Left side = table of contents. Each page = one job.

If you are on the team

  1. Open the page for your job (example: Aimme opens Client gifts).
  2. Read “What this is” and “Why it matters.”
  3. Do the numbered steps under “First things to do.”
  4. You’re done when the “You’re done when…” line is true.
  5. On Thursdays, write a short update on what moved.

If you are Justin

  1. Use Do this week as the lock list.
  2. You send event invites and set budgets.
  3. Everyone else runs the checklists.
