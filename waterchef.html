03 · Priority issues

Fix these first

1
Images missing alt text (sitewide)
OpenSEO flagged many product/pages with 6–12 missing alts each. Homepage: 3 missing. Theme gallery pattern — add real product alts; empty alt only when decorative.
2
Homepage missing og:image
Social shares look weak. Collections sample also missing OG image; product pages generally OK. Set default OG in Shopify + theme.
3
Duplicate meta · home ↔ /search
Same meta description on homepage and search. Noindex /search (and usually cart/login) or unique/empty meta on search.
4
Utility pages indexable
Crawl saw indexable /account/login, /cart, /search. Add noindex,follow on cart, account, search templates.
5
Typos & H1 polish
“Why Chose WaterChef?” → Choose. Collection title “Water FIltration”. U9000 H1 very long/keyword-heavy — human H1 + SEO title separately if needed.
6
Collection-scoped product URLs
URLs under /collections/shop-products/products/... not in sitemap while canonical /products/ exist. Internal links should use clean /products/ only.
7
Blog IA confusion
/blogs/news → 404. Hub at /pages/blog. Live blogs: water-101, drinking-water, etc. 301 dead paths; nav only live URLs.
8
Content opportunity (beyond tech)
Certification + contaminant hubs (PFAS, chlorine), filter finder, TrueHome whole-house intent pages. Expand thinner blog hubs.
