Preferred method: Collaborator access code

Per Shopify: you assign a 4-digit code under Users → Security. We enter that code when we request collaborator access from the Partner side. Only people with the code can request access. Shopify help

1. Open Users in Shopify admin

Sign in as the store owner (or someone who can manage users). Go to Settings → Users (on some stores this shows as Users & permissions).

2. Copy your collaborator access code

Click Security. In the collaborators section, click the 4-digit code to copy it. (You can also click Generate new code anytime — old codes stop working.)

3. Send Brandastic two things

Email or text us:

  • Your store URL (example: your-store.myshopify.com)
  • The 4-digit collaborator access code

Send to info@brandastic.com (or your Brandastic contact). We’ll request access from our Shopify Partner account.

4. Approve our collaborator request

After we submit the request, you’ll get an email and a notification in Shopify Home. Go to Settings → Users, open the request, review permissions, then Accept.

Give us what we need for the job (typical SEO / CRO / tracking work): themes, pages/products/collections/navigation as needed, apps, and relevant settings for domains/pixels.

5. Security notes (Shopify rules)

  • Partners must use two-step authentication or collaborator login won’t work.
  • Don’t share your owner password — code + approve is enough.
  • Collaborator access can expire after 90 days of inactivity; you can reactivate us later if needed.
  • You can reject a request or remove a collaborator anytime under Users.

Alternate: staff invite

If you prefer not to use collaborator codes: Settings → Users and permissions → Add staff → invite info@brandastic.com → grant theme / content / apps permissions → we accept the invite. Collaborator access is still preferred for Partner work.
